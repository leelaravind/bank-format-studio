# Icon-fix rebuild (2026-08-14) — release-candidate defect remediation

## Defect and root cause

**Observed:** after install and launch, the app window's title bar showed a
generic application icon; the installer UI showed no product branding.

**Root cause (title bar/taskbar):** `src/bfs_app/main.py` never set a Qt
window/application icon. The product icon embedded in the EXE's PE
resources (RT_ICON) covers Explorer, shortcuts and file-association
surfaces only; the running window's title bar, taskbar entry and Alt-Tab
tile use the **Qt window icon**, which Qt defaults to a generic icon unless
set explicitly at runtime. Automated release checks only inspected PE/ICO
resources, so the gap was invisible to them.

**Root cause (installer UI):** `installer.iss` set `SetupIconFile` (the
setup **file's** Explorer icon) but no `WizardSmallImageFile`/
`WizardImageFile`, so the wizard pages rendered without any product
branding.

## Fix

- `src/bfs_app/main.py`: new `app_icon()` resolves `logo.ico` from the
  PyInstaller bundle (`sys._MEIPASS`, i.e. `_internal\logo.ico`) when
  frozen — never a repository-relative path — and the repo copy in dev.
  Applied via `QApplication.setWindowIcon(...)` and
  `MainWindow.setWindowIcon(...)`. Also sets an explicit
  `AppUserModelID` (`ITISYOU.BankStatementFormatStudio.1`) via
  `SetCurrentProcessExplicitAppUserModelID` before `QApplication` so
  taskbar grouping/pinning binds to the product identity.
- `packaging/bfs.spec`: ships `packaging/logo.ico` in `datas` →
  `_internal/logo.ico` (runtime icon source for the frozen app).
- `tools/make_icon.py`: additionally generates Inno wizard bitmaps
  `wizard-small.bmp` (55px, text-free artwork), `wizard-small-2x.bmp`
  (110px, master artwork), `wizard-image.bmp` (164×314) and
  `wizard-image-2x.bmp` (328×628) from the same master artwork
  (`assets/logo/logo.png` untouched; `logo.ico` regenerated byte-identical).
- `packaging/installer.iss`: `WizardSmallImageFile=wizard-small.bmp,
  wizard-small-2x.bmp` (corner logo on every wizard page) and
  `WizardImageFile=wizard-image.bmp,wizard-image-2x.bmp` (welcome/finish
  banner).
- New regression tests: `tests/gui/test_gui_icon.py` (5 tests — window icon
  set and pixel-matches `logo.ico`, frozen-bundle resolution via
  `_MEIPASS`, no repo fallback when frozen, AppUserModelID) plus 2 new
  release-packaging tests (runtime wiring + `.ico` in spec datas; wizard
  BMP existence/dimensions/format + `.iss` directives). Suite grew
  262 → 269 tests.
