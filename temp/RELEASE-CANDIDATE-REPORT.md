## Known V1 Limitations

- Unsigned distribution consequences above (accepted, disclosed, £0 path)
- No lossless round-trip claim — by policy; information-loss report is the
  product mechanism
- xlsx output: content-deterministic everywhere; raw container bytes are only
  reproducible on the same zlib build (release builds use the pinned build
  environment, so shipped-artifact determinism holds)
- Fully offline by design: no update mechanism, no telemetry (SEC-01..05, SEC-21)
- Windows-only in V1 (macOS is a future path per PACKAGING-STACK-RESEARCH.md)
